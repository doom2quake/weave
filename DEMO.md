# Weave demo kit

Target length: 2 minutes 35 seconds. Record at 1440p or 1080p with the browser at 100 percent zoom.

## Before recording

1. Open the deployed HTTPS page in a normal browser and confirm the empty canvas is visible.
2. Open the same URL in ChatGPT's browser and confirm the Site tools menu lists nine tools.
3. Keep a clean copy of the exact prompt ready.
4. Clear the board and refresh the page.

## Shot list and narration

### 0:00 to 0:18, instant value

**Shot:** Start on the empty Weave page. Let the headline, single input, three examples, and empty canvas sit for two seconds.

**Narration:**

"Planning tools usually begin with setup. Weave begins with one sentence. There is no account, data import, template choice, or configuration. The page is ready the moment it opens."

### 0:18 to 0:55, local hero moment

**Shot:** Click **Build a sample plan**. Follow the activity rail while cards appear, links connect, groups form, schedule labels arrive, and the canvas settles into a timeline.

**Narration:**

"This Lisbon plan is built through the exact site tools the page registers. Each move is visible. Cards are added, dependencies are linked, related ideas are grouped, and eight items receive a place in the trip. Thirty-one real calls turn one thought into a usable timeline in seconds."

### 0:55 to 1:18, human control

**Shot:** Drag one card. Click another card's text and shorten it. Switch to Columns, then back to Timeline.

**Narration:**

"The result is not a transcript. It is a shared object you can touch. I can move a card, edit the wording, or choose the view that helps me think. The browser and the person work on the same plan, in the same place."

### 1:18 to 1:52, ChatGPT browser

**Shot:** Move to ChatGPT's browser. Show the Site tools menu briefly, then enter the exact prompt below. Let the first few calls visibly change the board.

**Narration:**

"In ChatGPT's browser, Weave exposes nine small, precise tools through `document.modelContext`. ChatGPT does not have to guess where to click. It can add, connect, group, schedule, arrange, summarize, and export through typed contracts while the page remains the shared workspace."

**Exact prompt:**

> Use this page's site tools to plan a 3-day Lisbon trip. Add a goal plus practical cards, link dependencies, group them into Prep, Lisbon days, and Day trip, schedule the trip across three days, reflow it as a timeline, summarize the plan, and export it as Markdown.

### 1:52 to 2:17, useful artifact

**Shot:** Show the summary panel. Click **Export .md**. Open the downloaded Markdown file and show its Plan, Schedule, and Connections sections.

**Narration:**

"The plan ends as something useful outside the demo. Weave creates a concise overview and exports the board as clean Markdown or structured JSON. Nothing is uploaded. The artifact is created and downloaded in this browser."

### 2:17 to 2:35, safety and close

**Shot:** Click the reset control. Hold on the confirmation dialog without approving, then return to the complete board.

**Narration:**

"Only clearing the board is destructive, so that tool pauses for a visible personal checkpoint. Every attempted move leaves a local receipt. Weave turns a thought into a plan you can see, shape, and take with you, with no setup at all."

## Recording notes

- Keep the cursor still while the sample sequence runs.
- Do not cut away during the card, link, group, and timeline transitions.
- Show the native Site tools menu long enough to read at least four tool names.
- Use the actual downloaded file. Do not substitute a prepared artifact.
- Keep the final video under three minutes and include spoken audio.
